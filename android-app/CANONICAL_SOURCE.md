# Fonte canônica do Android

Este diretório faz parte do repositório canônico **Tecnologia-odonto/Adesart**.

- As regras de negócio oficiais são as regras do Web/Backend canônico deste repositório.
- O Android não possui cópia própria de `supabase/functions` nem de `supabase/migrations`.
- Qualquer regra divergente trazida do antigo `vendamais-mobile` deve ser removida/substituída pela regra canônica.
- O repositório `DanielRochaOdo/vendamais-mobile` passa a ser somente origem histórica para esta importação e não deve receber novas regras de produto.
